Conseils du Royaume

Quand l'éclipse approche, la lune glisse vers le soleil dans le ciel : levez les yeux !

Pendant l'éclipse totale, les créatures des ténèbres déferlent. Restez groupés.

Ne fixez jamais le soleil sans casque d'éclipse : cuir, lingot de fer et verre teinté.
